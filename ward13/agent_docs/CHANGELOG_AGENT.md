# Agent change log

| # | Change | Why | Files |
|---|---|---|---|
| 0 | Added the QA harness, vendored three.js r128, agent docs, and a `renderInfo`/`AU`/`settings` test hook (only when `window.__W13_TEST`) | Phases 1–3: baseline evidence and repeatable tests | `tests/qa.mjs`, `vendor/`, `agent_docs/`, `index.html` (test hook only) |
| 1 | Added `cleanSettings()` with a schema (`SET_DEF`/`SET_RULE`). It runs at load and on every save. New keys `still`, `fov` and `captions` are reserved for R-07/R-08. | R-01: a corrupt `vol` made `audioInit` throw inside every click handler, so the menu was dead | `index.html` (settings section) |
| 2 | Added `repairSave()`. It rebuilds a v3 save field by field onto `newSave()` defaults, clamping and dropping malformed data. | R-02: a partial save crashed the shop and the game | `index.html` (settings section) |
| 3 | Added `dirReset()`, called from `startFloor`, `toMenu`, `die`, `completeFloor`, `fatal` and `pause` (crash only). The fake crash runs at most once per session, never on floors 1–2, and scares don't repeat back to back. The glitch timer is now dt-based. | R-03 and R-10: the fear director leaked its overlay and muted audio into the menu, the meta-scare repeated, and the twitch rate depended on frame rate | `index.html` (DIR, flow, `secMotion`) |
| 4 | `nmap`: precomputed row offsets, no `%`, `sqrt` instead of `Math.hypot`. `rmap`: works at half resolution and applies puddles only inside each puddle's bounding box. | R-04: `rmap` (added in an earlier pass) was the single biggest JS cost of a floor load | `index.html` (procedural textures) |
| 5 | `tools/build.mjs` inlines `vendor/three.min.js` and writes `Ward13.html` (`--check` mode for QA). `index.html` falls back to `vendor/three.min.js` if the CDN fails. | R-05: the game could not start offline | `tools/build.mjs`, `Ward13.html`, `index.html` (boot script) |
| 6 | `perf()` rewritten with hysteresis and recovery. Added `perfSettle()` after loads, resume and notes. The "too slow" level becomes a per-floor ceiling. | R-06: dynamic resolution only ever degraded, so one hitch lowered quality for the whole session | `index.html` (safety nets, flow) |
| 7 | Trauma² camera shake from smooth sines. New settings: field of view, reduced camera motion, captions. Escape closes the settings and controls panels. Settings rows are more compact. | R-07: shake read as jitter; motion-sensitive players had no options; Done was below the fold | `index.html` (`syncCamera`, settings UI, input) |
| 8 | Caption system `cap()`/`capClear()` with direction and distance. It wraps 9 `SFX` cues and is called from enemy steps, `sob`, `lockerBang`, the phone, the stalker and the footsteps scare. | R-08: gameplay-critical sounds had no text equivalent | `index.html` (audio, voices, director) |
| 9 | `fatal()` now shows a "Something went wrong" panel (Return to the menu restores the floor snapshot; Reload). The loop stops simulating and rendering after a crash. | R-09: a frozen frame with no way out | `index.html` (flow, loop, screens) |
| 10 | Contextual one-shot tips (`TIPS`, `updTips`) replace the floor-1 three-mechanic message. | R-11: teach by doing | `index.html` (flow, update) |
| 11 | Gamepad support: `pollPad` (standard mapping, dead-zones, analog movement scaling). `playKey()` is now the single action path for keyboard and pad. D-pad and A navigate menus, with `.padf` focus styling. Any pad button skips the intro. The controls screen and menu copy were updated. | R-12: pad support. Fixed: a pad-only player could not leave the intro. | `index.html` (input, intro, `updPlayer`, CSS) |
| 12 | `PERF.calls`/`PERF.tris` are captured after the scene pass, for `renderInfo()`. | R-13: dev stats measured the full-screen quad by mistake | `index.html` (`renderScene`, test hook) |
| 13 | Polish: a refused item use now says why ("No pills left" / "Your mind is steady"). Below 700 px wide the item belt moves above the status card, and the resize test now checks for overlap. The floor-1 hint no longer says "three fuses" (the count varies). | Phase 5: feedback, layout, copy | `index.html` (`useItem`, CSS, `HINTS`), `tests/qa.mjs` |
| 14 | In the `loading` state the loop presents one black frame and then stops rendering until the floor is ready. | Phase 6: root cause of a load regression found by A/B. Stale frames rendered behind the title card stalled the level build's GPU sync points. Floor-30 load is now −52% against base. | `index.html` (loop) |
| 15 | Defensive: the black loading frame is also presented on the first floor, when no world exists yet. A suspected stale-frame regression was **not reproduced**; the previous build was also dark mid-load (11.5/255). The fake-crash text is now browser-neutral (it used Chrome's "Aw, Snap!", which reads wrong in Firefox or Safari). `msg` is exposed to the test hook. The `edges` QA scenario was added. | Phase 7–8 | `index.html` (loop, `sigCrash`, test hook), `tests/qa.mjs` |
| 16 | The map uses distinct shapes per marker (square exit, diamond objective, ring code digit, cross threat), with a legend on the Controls screen. The `map` QA scenario was added. The `tips` test is robust to the floor hint's real-time timer. | Phase 8: the red and green markers were distinguishable by color only (colorblind accessibility) | `index.html` (`drawMap`, controls copy), `tests/qa.mjs` |
